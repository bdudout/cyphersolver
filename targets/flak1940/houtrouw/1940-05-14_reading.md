# 14 May 1940: reading (radio text with word division, and German), by Jacob Houtrouw (issue #602), copied from the issue as posted on 14 Nov 2026

Notation (the contributor's): In the radio text, [x/y] means the word wants x and the first reading had y. Brackets mark the sheet's own slips and some of the letters corrected after the key was known; the lists above give all of both. A letter in brackets alone was lost from the film and is supplied from the words; ‖ marks a part break; X is the sender's separator.

#### The message (teleprinter copy: frame 1048, SRO 0132, accepted 14 May 1940 15.35, passed on 16.55 and 17.00)

*Radio text, with word division*
GEHEIME KOMMANDOSAQE X ROEM X ZWEI X ZUG X VIER X STRIQ X VIERNEUNEINS X HAT AM X EINSDREI X FUENF X VIERNULL X STELLUNGSWEQSEL VON X TITISEE X NAQ BAHNHOF X HAUSACH X DURQGEFUEHRT UND IST SEIT X EINSVIER X FUENF X VIERNULL X ‖ X NULLFUENFNULLNULL X UHR ZUM SQUTZE DER HEERESEINHEIT X SIEBENNULLEINS X FE[U/N]ERBEREIT X FLUGABWEHRKOMMANDO X SCHWARZWALD X ROEM X EINS X CAESAR X NR X FRITZ X EINSVIEREINS X STRIQ X VIERNULL X GKDOS X

*German*
Geheime Kommandosache. II. Zug 4./491 hat am 13.5.40 Stellungswechsel von Titisee nach Bahnhof Hausach durchgeführt und ist seit 14.5.40 05.00 Uhr zum Schutze der Heereseinheit 701 feuerbereit. Flugabwehrkommando Schwarzwald I c, Nr. F 141/40 g.Kdos.
